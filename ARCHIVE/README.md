# 历史存档（ARCHIVE）

本目录只保存与当前实现不兼容、或已被现行文档取代的历史资料：审查报告、诊断、提案、旧发布说明、旧实现记录与历史文件清单。

## 使用约束

- **默认不扫描**：Agent、脚本与全文检索不应遍历本目录，也不要把这里的结论当作当前事实源、配置模板或检查依据。
- 仅在用户明确要求追溯某段历史时，按精确路径读取单个文件；不要因关键词命中而批量检索。
- 历史记录保留当时的路径、文件名、配置格式与验证读数；其中可能提到已删除的文件（如旧架构长文、英文文档）或已退役的流程，均属历史事实，不据此恢复。
- 当前资料从[文档导航](../docs/README.md)进入；当前实现变更记录见[实现变更记录](../docs/changelog/implementation-notes.md)。
