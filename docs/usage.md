# 使用说明

[文档导航](README.md) · [配置说明](configuration.md) · [README](../README.md)

## 启动（唯一入口）

```bash
python -m src.main
```

是否同时启动 Web 管理面板由 `config/config.toml` 的 `[Web] web_enable` 决定（默认 `false`，即纯命令行录制）。设为 `true` 后，同一条命令会额外监听面板端口，浏览器访问 `http://localhost:8000`。`python -m src.web` 不再是启动方式（`src/web.py` 只是面板实现模块）。

## Web 管理面板

- **仪表盘**：实时查看监测/录制数、错误数、磁盘剩余、录制中列表、日志流（SSE 推送）
- **直播间管理**：在线增删改查直播间地址、启用/禁用（自动热加载到录制主循环）
- **配置编辑**：在线编辑 config.toml 各项（录制设置/推送/Cookie 等），敏感配置项脱敏
- **文件浏览**：浏览 downloads 目录并下载录制文件
- **实际画质展示**：录制表格显示「设置画质/实际画质」，降级时标红高亮
- **弹幕查看**：读取弹幕监控枢纽快照，实时展示各房间弹幕事件
- **语言切换**：顶栏语言选择器，中英文即时切换（写回配置并热切换进程内翻译，无需重启）

Web 与命令行共用同一录制引擎与配置文件，直播间地址的增删改会自动被录制主循环热加载。后台运行模式：将 `web_show_console` 设为 `false`，Windows 下会隐藏控制台窗口，日志写入 `logs/web_console.log`。

接口路由、认证与安全边界见 [Web 面板与接口](architecture/web.md)。

> ⚠️ **安全提示**：默认仅监听 `127.0.0.1` 且未启用认证；若为 Docker / 局域网 / 公网访问改绑 `0.0.0.0`，必须同时开启 `web_auth_enable` 并设置强密码。

## 录制格式推荐

- **长时间录制**：推荐 `ts` 格式，实时写入，断电不易损坏
- **短时间录制**：推荐 `mp4` 或 `mkv` 格式，录制完成后直接可用
- **仅音频录制**：推荐 `mp3` 或 `m4a` 格式

## 画质说明

| 画质代码 | 中文名 | 说明 |
| --- | --- | --- |
| OD | 原画 | Original Definition，最高画质 |
| BD | 蓝光 | Blu-ray，超高清 |
| UHD | 超清 | Ultra HD |

支持实际画质回采与降级告警的平台：抖音、TikTok、快手、虎牙、斗鱼、B站、网易CC。实际下发画质低于设置时自动告警并标记。实现细节见 [平台解析与画质](architecture/platforms.md)。

## 采集方式选择（HLS/FLV）

拉流源在 HLS（m3u8，逐段拉取）与 FLV（单条长连接）之间自动选择：默认优先 HLS，校验不可达时按序回退 FLV，最后兜底 `record_url`。由两个配置项控制：

| 配置项 | 作用 |
| --- | --- |
| `是否启用HLS采集(是/否)` | 全局开关：开启（默认）时优先 HLS，不可达或源不存在时回退 FLV；关闭则所有平台只走 FLV 等非 HLS 候选 |
| `HLS采集排除平台(逗号分隔)` | 平台级排除：命中平台无视全局开关、恒按 FLV 采集，HLS 源不参与候选与回退 |

- **适用场景**：整体偏好 HLS，但个别平台 HLS 不稳定或被风控时，把该平台加入排除列表，无需关闭全局开关。
- **填写格式**：平台名须与日志/配置显示的完全一致（如 `斗鱼直播`，不能简写为 `斗鱼`）；多个平台中英文逗号均可；留空不排除。
- **优先级**：排除列表优先于全局开关；列表外平台仍按全局配置。
- **边界行为**：排除平台若只有 HLS 源且无 FLV/`record_url` 可回退，本轮放弃录制并告警；h265 FLV 源不再触发切换 HLS（h265 FLV 自动改存 TS 的逻辑不受影响）。
- **热更新**：下一轮监测读取新配置，无需重启。

## 弹幕录制与弹幕监控

两套开关相互解耦，可单独或同时开启：

| 配置项 | 作用 |
| --- | --- |
| `是否录制弹幕(是/否)` | 弹幕落盘为 SRT 字幕，与视频录制同起同停 |
| `是否弹幕监控(是/否)` | 仅实时查看弹幕，不写 SRT（Web `/api/danmaku`） |
| `弹幕分片时长(秒)` | SRT 分片粒度，建议与「视频分段时间(秒)」一致 |
| `弹幕录制平台(逗号分隔)` | 启用弹幕的平台白名单 |

- **支持平台（5 个）**：抖音直播、斗鱼直播、虎牙直播、B站直播、TwitchTV
- **输出文件**：SRT 与视频分片一一对应，命名为 `{基础名}_{分片序号:03d}.srt`（如 `_000.srt` 对应 `_000.ts`）；未分段时为 `{基础名}.srt`。时间轴以采集启动后的单调时钟为基准，按分片时长重置字幕片内时间，可由播放器加载；不保证与媒体 PTS 精确同步
- **弹幕代理**：通用 WebSocket 默认直连，平台可显式传入代理；Twitch 未指定代理时还会读取系统 HTTP/HTTPS 代理。异常排查见 [FAQ](faq.md)
- **监控边车日志**：弹幕监控事件同时写入 `logs/danmaku_monitor.jsonl`（5MB 轮转）
- 抖音弹幕在 Cookie 为空时自动获取访客 ttwid；B站弹幕自动获取真实 buvid（登录 cookie → spi 接口 → 首页 Set-Cookie → 随机兜底）

协议与实现见 [弹幕与字幕](architecture/danmaku.md)。

## 主播名自动更新

开启 `是否自动更新主播名(是/否)`（默认开启）后，平台改名会同步到房间列表及录制目录/文件；关闭则保持手填名称。完整顺序、合并规则和异常处理见 [主播名自动更新实现](architecture/configuration.md#主播名自动更新)。

## 多语言与界面切换

提供中文和英文，默认中文；仅英文加载 `i18n/en_US.json`：

| 语言码 | 显示名 | 目录文件 |
| --- | --- | --- |
| `zh_CN` | 中文 | 源码原文，无需翻译文件 |
| `en_US` | English (US) | `i18n/en_US.json` |

- 配置键 `language`：留空使用中文；`en` / `en-US` / `en-GB` 归一为英文，中文地区码归一为中文；未知值或英文目录不可用时回退中文。
- **热切换**：Web 面板顶栏语言选择器、直接编辑 `config.toml` 两种途径均可切换；命令行主循环每轮检测配置变化并即时重载翻译，无需重启（录制中的 ffmpeg 子进程不受影响）。
- 不依赖 `LANG` / `LANGUAGE` 环境变量；只需维护 `i18n/en_US.json`。

## 停止录制

- **Windows / Linux / macOS**：命令行按 `Ctrl+C`
- **Docker**：执行 `docker compose stop`

## 注意事项

1. 录制 TikTok、SOOP(原AfreecaTV) 等海外平台时，请在配置中开启代理。
2. 长时间挂机建议把循环时间设长一些（如 60 秒），避免请求频繁被封 IP。
3. 直播结束后会自动保存文件，无需手动停止。
4. 录制的视频文件损坏时，建议改用 `ts` 格式。
5. 录制抖音需要有效 Cookie（至少包含 ttwid），否则可能触发风控。
6. 部分平台需要 Node.js 运行 JavaScript 签名脚本，Windows 下会自动安装。

## 常见平台链接形态

**斗鱼**：`https://www.douyu.com/8751648` 与移动端 `https://m.douyu.com/8751648` 走同一套录制流程。尾斜杠、查询参数（`?rid=`、`?dyshid=`）、`http://` 与附加路径均可识别；字母号与分享链接先还原为数字房间号再取流，非法链接给出明确错误（入日志前脱敏）。

**B站**：`https://live.bilibili.com/22747736` 与 `https://b23.tv/22747736` 走同一套流程。数字短域可直接识别；字母短码（如 `https://b23.tv/ZyQrgYf`）先跟随 302 解析真实房间号（进程内缓存）再取流。

**虎牙**：`https://www.huya.com/30764624` 与 `https://hy.fan/30764624` 走同一套流程。字母短码（如 `https://hy.fan/JbmwoV`）先跟随 301 解析真实房间段（进程内缓存）再归一为桌面链接。

更多平台链接与解析约束见 [平台解析与画质](architecture/platforms.md)。
